# bms2mania 1차 MVP 요구사항

7키 BMS 채보를 osu!mania 7K 비트맵(.osz)으로 변환하는 JavaFX 데스크톱 프로그램의 1차 MVP 요구사항입니다.
파일 형식 자체에 대한 설명은 [format.md](./format.md)를 참고하세요.

## 2. 기능 1 — BMS 폴더 스캔·검색

- 사용자가 지정한 BMS 폴더를 재귀적으로 스캔한다.
- 스캔 대상 확장자는 `.bms`, `.bme`, `.bml`이다.
- **7키 판별은 채널 기준**으로 한다. 아래 두 조건을 모두 만족해야 목록에 올린다.
  - 2P 채널(`2x`, `4x`, `6x`, `Ex`)이 없다.
  - 1P 6·7번 키 채널(`18`, `19` 또는 `58`, `59`)을 사용한다.
- 스캔은 백그라운드에서 진행률을 표시하며 실행한다.
- 스캔 결과는 캐시로 저장한다. 사용자가 "다시 스캔" 버튼으로 갱신할 수 있다.
- 검색 대상: 제목, 아티스트, 난이도표 레벨(예: `st12`)
- 변환은 **채보 1개를 선택**해서 실행한다.

## 3. 기능 2 — 난이도표

### 3-1. 내장 난이도표

| 표 | 기호 | 등록 URL | 비고 |
|---|---|---|---|
| Satellite | `sl` | `https://stellabms.xyz/sl/table.html` (페이지) | header URL 미확인 |
| Stella | `st` | `https://stellabms.xyz/st/table.html` (페이지) | header URL 미확인 |
| Dystopia | `dy` | 페이지 `https://monibms.github.io/Dystopia/dystopia.html`<br>header `./dystopia_header.json` (상대 경로) | data URL이 Google Apps Script(리다이렉트됨) |
| 제3기 Overjoy | `oj` | header `https://rattoto10.github.io/second_table/overjoy_header.json` | 페이지는 `http://rattoto10.jounin.jp/table_overjoy.html` |

- 위 URL은 사용자 제공 캡처와 조사 결과를 옮긴 것이다. **실제 응답 내용은 구현 시 확인한다.**
- 표 기호는 각 표의 header에 있는 `symbol`을 쓰지 않고, 위 표처럼 **알파벳 2글자로 고정**한다.

### 3-2. URL 처리
- header URL을 기준으로 저장한다. data URL은 동기화할 때마다 header의 `data_url` 값을 읽어 계산한다.
- 상대 경로는 기준 URL로 해석한다(`URI.resolve`).
- HTTP 리다이렉트를 따라간다.
- 페이지 URL(HTML의 `<meta name="bmstable">`)도 입력으로 받을 수 있게 한다.

### 3-3. 동기화
- 프로그램 실행 시 백그라운드에서 최신 표를 동기화한다.
- 화면에 **동기화 버튼**과 마지막 동기화 시각을 표시한다.
- 동기화에 실패하면 마지막으로 받은 캐시를 사용한다.
- 캐시는 사용자 홈 폴더 아래(예: `~/.bms2mania/`)에 저장한다.
- 표 데이터는 레포와 배포 파일에 포함하지 않는다.

### 3-4. 채보 매칭
- 차트 데이터의 `md5`와 `sha256`을 모두 지원한다. 한쪽 값이 비어 있거나 `"null"`인 항목이 있다.
- 해시는 **디코딩 전 원본 파일 바이트**로 계산한다.

## 4. 기능 3 — 변환 (BMS → osu!mania 7K)

### 4-1. 메타데이터

| osu 항목 | 값 |
|---|---|
| Title / TitleUnicode | `TITLE SUBTITLE` 원문 그대로 (공백 구분, 제목에 같은 문자열이 이미 있으면 부제 생략) |
| Artist / ArtistUnicode | `#ARTIST` 원문 그대로 |
| Creator | `bms2mania` |
| Version | 난이도표 레벨. 예: `st12`<br>여러 표에 있으면 `st12 / dy7` (순서: sl → st → dy → oj)<br>어느 표에도 없으면 `Unlisted` |
| Tags | Version과 같되 슬래시 없이 공백 구분. 예: `st12 dy7`<br>Unlisted면 비움 |
| OverallDifficulty | 8 (고정) |
| HPDrainRate | 7 (고정) |
| CircleSize | 7 |
| PreviewTime | -1 |

### 4-2. 문자 인코딩
- 입력은 인코딩 판별 라이브러리로 자동 판별한다.
- 제목이 깨져 보이면 사용자가 인코딩을 직접 바꿀 수 있는 옵션을 둔다.
- 출력 `.osu`는 UTF-8로 저장한다.
- 일본어 등 원문은 깨지지 않아야 한다.

### 4-3. 채보 변환
- **레인 매핑**: 채널 `11, 12, 13, 14, 15, 18, 19`를 레인 `0~6`으로 매핑한다.
- **버리는 것**: 스크래치(`16`, `56`), 프리존(`17`), 숨김 노트(`3x`), 지뢰(`Dx`), BGA 채널
- **롱노트**: `#LNTYPE 1`(5x 채널)과 `#LNOBJ`를 osu 롱노트(type 128)로 변환한다.
- **타이밍**: BPM 변경(`03`), 확장 BPM(`08`), 마디 길이(`02`), STOP(`09`)을 반영한다.
  - STOP은 시간만 뒤로 민다. 정지 화면 효과는 MVP 이후에 다룬다.
  - 속도 통일(SV 정규화)은 하지 않는다. BMS처럼 BPM에 따라 속도가 바뀐다.
- **`#RANDOM`**: 항상 1번 분기를 선택하고, 리포트에 표시한다.

### 4-4. 오디오
- 처리 순서:
  1. ffmpeg로 키음을 PCM으로 디코딩한다.
  2. **Java로 시간 배치·믹싱·정규화**한다.
  3. ffmpeg로 **mp3 192kbps**로 인코딩한다.
- 믹싱 규칙:
  - BGM, 보이는 노트, 롱노트 시작음을 넣는다.
  - 숨김 노트, 지뢰, 롱노트 끝음은 넣지 않는다.
  - 같은 WAV ID는 동시에 한 소리만 낸다. 다시 재생되면 이전 소리를 끊는다.
  - `#WAV`에 적힌 파일이 없으면 확장자만 다른 같은 이름의 파일을 찾는다.
  - 소리가 겹쳐 찢어지지 않도록 볼륨을 정규화한다.
- 무음 샘플 파일을 `.osz`에 넣어 osu 기본 타격음을 끈다. (실제 동작 검증 필요)
- ffmpeg 경로가 유효하지 않으면 변환 버튼을 비활성화하고 설치 안내를 표시한다.
- 디버그용 **"채보만 변환"** 모드: 음원 없이 `.osu`만 생성한다.

### 4-5. 기타 출력
- **배경 이미지**: `#STAGEFILE` → `#BACKBMP` 순으로 찾아 PNG로 변환해 포함한다.
- **`.osz` 파일명**: `Artist - Title [Version].osz`
  - Version이 `Unlisted`이면 끝에 파일 해시 앞 8자리를 붙인다. 예: `Artist - Moon [Unlisted] (a1b2c3d4).osz`
  - Windows에서 쓸 수 없는 문자(`\ / : * ? " < > |`)는 치환한다.
- **변환 리포트**: 없는 키음 파일, 버린 노트 수(스크래치 등), `#RANDOM` 처리 내역, 경고를 표시한다.

## 5. 개발·레포 운영

- 테스트용 BMS는 **직접 만든 작은 BME와 짧은 비프음 키음**만 레포에 포함한다.
- 실제 곡의 BMS·키음은 저작물이므로 레포에 올리지 않는다. `.gitignore`에 등록한 로컬 폴더에서만 사용한다.
- ffmpeg가 필요한 테스트는 JUnit `@Tag`로 분리한다. ffmpeg가 없는 환경에서도 나머지 테스트는 실행되게 한다.

## 6. 알려진 제약과 추후 과제

- 파일명 해시는 Unlisted 채보에만 붙인다. 난이도표에 있는 채보끼리도 드물게 파일명이 겹칠 수 있다. 문제가 생기면 적용 범위를 넓힌다.
- STOP 구간의 정지 화면 효과, 속도 통일 옵션은 MVP 이후 검토한다.
- 일괄 변환, 같은 곡 난이도 묶기, 스크래치 비율 표시, 난이도표 기준 탐색, 변환 이력 추적, osu Songs 폴더로 바로 내보내기는 MVP 이후 후보다.
- 아래 항목은 구현 단계에서 실제로 확인해야 한다.
  - osu가 UTF-8 `.osu`를 제대로 읽는지
  - 무음 샘플로 기본 타격음이 꺼지는지
  - 각 난이도표 URL의 실제 응답
