# bms2mania

7키 BMS 채보를 osu!mania 7K 비트맵(.osz)으로 변환하는 데스크톱 프로그램입니다.

> 🚧 개발 중입니다.

## 주요 기능 (1차 MVP 목표)

- BMS 폴더 스캔 및 7키 채보 검색
- 난이도표(Satellite, Stella, Dystopia, 제3기 Overjoy) 레벨을 비트맵 난이도 이름에 표기
- 키음을 하나의 음원(mp3)으로 합성해 .osz로 변환
